# DepoLens

흩어진 논문 속 증착 조건을 한 번에 모아, 가장 가능성 높은 두께부터 단계별로 안내하는 길잡이입니다. 정답을 주는 도구가 아니라 소자를 만드는 횟수를 줄이는 도구입니다.

사이트: https://heonjaelee-tech.github.io/depolens/

## 쓰는 순서

1. 소자 조건: 소자 역할(FeFET, TFT, MFM, MIM)을 고르고 층마다 물질, 두께, 증착 방법을 넣으면 3D 구조가 바로 바뀝니다. 최적화할 층과 목표 성능을 고릅니다.
2. 논문 분석: 그 물질과 지표에 대해 모아 둔 논문 값, 뺀 논문과 이유, OpenAlex 검색 결과를 한 화면에 보여 줍니다. 논문 값을 직접 추가할 수도 있습니다.
3. 단계별 실험 계획: 논문 경향으로 계산한 목표 달성 확률이 가장 높은 두께부터 제시합니다. 설계 규칙상 위험한 두께는 후보에서 뺍니다.
4. 결과 입력: 측정값을 넣으면 우리 공정 수준에 맞춰 다시 계산하고 다음 두께를 추천합니다.

## 정확도

논문 한 편을 빼고 나머지로 학습해 뺀 논문의 값을 맞히는 방식으로 잽니다. 결과가 나빠도 그대로 공개하고, 모델을 바꿀 때마다 이전 결과를 함께 남깁니다. 현재 데이터(HZO 2Pr, 논문 9편 15개 값)로는 논문만으로 절대값을 맞히는 힘이 약해, 시작 두께와 다음 두께를 고르는 용도로 씁니다.

## 파일

- `index.html`, `tool.js`, `tool.css`: 두께 가이드
- `model.js`: 두께 경향 모델 (논문별 수준 차이 + 공통 모양, 부트스트랩 불확실성)
- `data/hzo_2pr.json`: HZO 2Pr 논문 데이터와 검증 결과
- `nand.html`, `app.js`: 3D NAND 셀 TCAD 계산 결과 (덤)
