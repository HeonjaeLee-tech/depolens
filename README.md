# DepoLens

흩어진 논문 속 증착 조건을 한 번에 모아, 가장 가능성 높은 두께부터 단계별로 안내하는 길잡이입니다. 정답을 주는 도구가 아니라 소자를 만드는 횟수를 줄이는 도구입니다.

사이트: https://heonjaelee-tech.github.io/depolens/

## 무엇을 하나

신소재가 나오면 지금은 후보 조건 수십, 수백 개를 TCAD로 모두 돌리거나 직접 만들어 봅니다. DepoLens는 그 앞에서 논문 근거로 불가능한 조건을 지우고 가능성이 높은 몇 개만 남깁니다. TCAD를 대신하지 않고, TCAD에 보낼 조건 수를 줄이는 도구입니다. TCAD가 없는 연구실은 여기서 바로 첫 제작 조건을 고릅니다.

## 쓰는 순서

1. 만들려는 소자: FeFET, TFT, MFM, MIM, 신구조(구조 이미지 첨부) 중 고르고 층마다 물질, 두께, 증착 방법을 넣습니다. 오른쪽 화면에서 3D 구조가 돌고, IV 측정과 열(커패시터는 전계) 분포가 움직입니다. 설계가 위험하면 해당 층이 붉게 깜빡이고 이유를 물어볼 수 있습니다.
2. 증착 조건 탐색: 논문 조건을 모아 단계별 레시피, 공정 창, ALD 사이클, 9회 실험표와 성공 확률을 보여 줍니다. 공개 페이지에서는 미리 돌려 저장한 예시 분석을 보여 주고, Claude 앱에서 열면 SciSpace 검색과 AI 분석이 실시간으로 돕니다.
3. 제작된 소자: 단계별 예상 IV와 밴드 다이어그램, 3D NAND 스트링 TCAD 결과(미리 계산)를 봅니다.

## 장비 실험 기록

우리 장비로 해 본 조건과 측정값(직접 입력 또는 CSV)을 넣으면 논문 사이의 연구실 차이 대신 우리 장비 값으로 예측을 다시 맞춥니다. HZO 2Pr은 실제 논문 9편으로 만든 두께 모델에서 예측 범위가 얼마나 좁아지는지 숫자로 보여 줍니다. 데이터가 쌓일수록 돼지가 자랍니다.

## 정확도

논문 한 편을 빼고 나머지로 학습해 뺀 논문의 값을 맞히는 방식으로 잽니다. 결과가 나빠도 그대로 공개하고(두께 모델 검증 페이지), 모델을 바꿀 때마다 이전 결과를 함께 남깁니다. 열 분포는 2D 열전도 1차 근사이고 TCAD 결과가 아닙니다.

## 파일

- `index.html`, `live.js`: 3단계 도구와 실시간 미리보기
- `examples/`: 저장된 예시 분석 (논문은 SciSpace 실제 검색 결과, 확률은 AI 추정)
- `model.js`, `data/hzo_2pr.json`: HZO 두께 모델과 데이터
- `guide.html`, `tool.js`: 두께 모델 검증
- `nand.html`, `app.js`, `data/nand_res.json`: 3D NAND 셀 TCAD 결과
