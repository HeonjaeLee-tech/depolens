# DepoLens

신물질의 증착 레시피 후보를 논문 근거로 고르고, 그 조건으로 만든 소자를 오픈소스 TCAD(DEVSIM)로 먼저 계산하는 도구입니다.

사이트: https://heonjaelee-tech.github.io/depolens/

## 사이트에서 볼 수 있는 것

- 3D NAND 셀 단면 계산 결과: 게이트 전압에 따라 전자 농도, 전위, 전기장, HZO 분극이 바뀌는 모습과 선택 셀의 전류–전압 곡선
- 실험 계획: 증착 온도, 사이클 수, 후열처리 온도 27가지 조합을 직교 배열 9회로 줄인 설계
- 기존 TCAD와의 비교, 결과를 확인한 방법

사이트의 단면과 곡선은 DEVSIM 2D 원통 좌표(r–z) 계산 결과를 저장해 두고 보여 줍니다.

만든 사람: 이헌재, 한양대학교 전자공학부
